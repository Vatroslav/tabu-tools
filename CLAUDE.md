# tabu-tools

Javni repo. Sve što se ovdje commita (kod, komentari, README, commit poruke) vidi cijeli internet.

- Ovdje ide samo sadržaj alata namijenjen javnosti.
- Bez bilješki, odluka, planova, analitike, naziva privatnih repoa i ičega o autoru osobno - to ide u privatni repo.
- Komentari u kodu neutralni i tehnički, na engleskom. Commit poruke kratke i opisne, bez internog konteksta.
- Deploy: GitHub Pages iz `main`, root folder; custom domena u `CNAME`.
